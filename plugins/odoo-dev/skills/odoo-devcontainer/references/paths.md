# Key Paths

| What                      | Path                                         |
| ------------------------- | -------------------------------------------- |
| Custom addons (workspace) | `/mnt/extra-addons`                          |
| Community source          | `/usr/lib/python3/dist-packages/odoo`        |
| Community addons          | `/usr/lib/python3/dist-packages/odoo/addons` |
| Enterprise addons         | `/var/lib/odoo/addons/$ODOO_VERSION`         |
| Config                    | `/etc/odoo/odoo.conf`                        |
| Data dir                  | `/var/lib/odoo`                              |
| Python venv               | `/mnt/extra-addons/.venv`                    |
| Odoo binary               | `/usr/bin/odoo`                              |
